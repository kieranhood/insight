# Insight

Insight by 50N Systems is an on-board monitoring and diagnostic platform for
yacht hotel IT. It brings together information from the yacht's Peplink
router, UniFi switches, Ruckus Unleashed Wi-Fi and Starlink connection,
identifies likely problems, and explains them in plain English for crew,
with the technical evidence remote support engineers need.

Planning lives in `openspec/`. Integration research is in `docs/integrations/`.
